# הקמת שליחת מייל לדו"ח החודשי

מדריך קצר. הקוד כבר פרוס ומוכן — חסרה רק הגדרה אחת.

**מה כבר עובד בלי כלום:** בהנה"ח של השכרות, כפתור **"תצוגה מקדימה"** מראה את הדו"ח האמיתי.
כדאי להסתכל לפני שמגדירים שליחה.

---

## שלב 1 — לשלוח לעצמי (5 דקות, בלי DNS)

### 1.1 חשבון Resend
היכנס ל-**https://resend.com** והירשם.

> **חשוב:** הירשם עם `a0556773669@gmail.com`. בשלב הזה המערכת שולחת מכתובת הבדיקה של
> Resend, והיא מגיעה **רק לכתובת שאיתה נרשמת**.

### 1.2 מפתח API
בתפריט הצדדי: **API Keys** → **Create API Key** → שם: `ultranet` → **Add**.
העתק את המחרוזת שמתחילה ב-`re_`. **היא מוצגת פעם אחת בלבד.**

### 1.3 להגדיר ב-Vercel
**https://vercel.com** → הפרויקט `ultranet-platform` → **Settings** → **Environment Variables**:

| Key | Value |
|---|---|
| `RESEND_API_KEY` | המחרוזת שהעתקת (`re_...`) |

סמן את שלוש הסביבות (Production / Preview / Development) → **Save**.

### 1.4 Redeploy
**Deployments** → הפריסה העליונה → תפריט `...` → **Redeploy**.

> Vercel לא טוען משתנים חדשים לפריסה שכבר רצה. בלי הצעד הזה כלום לא ישתנה.

### 1.5 לבדוק
בהנה"ח של השכרות → **"שלח מייל לבדיקה"** → בבורר העליון בחר **"המייל שלי"** → **שלח**.
המייל אמור להגיע תוך פחות מדקה.

## שלב 2 — לשלוח לשותפים (אחרי שבדקת)

כל עוד לא עשית את זה, שליחה לסניפים **תיכשל**. המערכת מציגה על זה אזהרה אדומה.

### 2.1 לאמת דומיין
Resend → **Domains** → **Add Domain** → הדומיין שלך.
Resend תיתן כמה רשומות DNS (SPF ו-DKIM). צריך להדביק אותן אצל מי שמנהל לך את הדומיין,
ואז ללחוץ **Verify**. האימות לוקח בין כמה דקות לכמה שעות.

### 2.2 להוסיף כתובת שולח ב-Vercel

| Key | Value |
|---|---|
| `REPORT_FROM_EMAIL` | `אולטרנט <reports@הדומיין-שלך>` |

ואז **Redeploy** שוב.

### 2.3 כתובות המייל של הסניפים
לכל סניף צריכה להיות כתובת — בשדה `partnerEmail` בכרטיס הסניף, או משתמש במערכת שמשויך
לסניף. הדיאלוג של **"שלח לכל הסניפים"** מראה לפני השליחה בדיוק למי הולך ומי חסר.

## שלב 3 — שליחה אוטומטית ב-1 לחודש (רשות)

### 3.1 סוד ל-cron
Vercel → **Settings** → **Environment Variables**:

| Key | Value |
|---|---|
| `CRON_SECRET` | מחרוזת אקראית ארוכה שתמציא |

### 3.2 להוסיף `vercel.json` בשורש הפרויקט
```json
{
  "crons": [
    { "path": "/api/rentals/monthly-reports", "schedule": "0 6 1 * *" }
  ]
}
```
זה מריץ ב-1 לכל חודש ב-06:00 UTC, ושולח את הדו"ח של **החודש שנסגר**.
Vercel שולחת את `CRON_SECRET` לבד — לא צריך להגדיר כלום נוסף.

סניף שכבר קיבל את הדו"ח לאותו חודש מדולג, אז אפשר להריץ שוב בלי לשלוח פעמיים.
